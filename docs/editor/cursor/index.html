常用必背快捷键​

代码中打开快速对话​

ctrl + k 内部对话框

用途：

注释, 选中代码块， ctrl + K ， 帮我注释， enter

修改代码

如果需要多轮对话 ctrl + enter

在终端中写shell命令，终端中ctrl + K

在选择的某个文件夹中查找内容​

选中文件夹 shift + alt + f

全局搜索文件名字​

ctrl + p

打开关闭左侧文件树​

ctrl + b

上下移动行代码​

alt + ↑/↓

上下复制行代码​

shift + alt + ↑/↓

单文件修改变量名及引用处修改​

f2 (继承vscode功能，只作用于单文件中的定义和所有引用处修改，不会修改其他文件的引用和定义，如需要用对话框修改)

折叠代码块​

ctrl + shift + []

加减行缩进​

ctrl + []

扩大缩小选择范围​

ctrl + alt + ↑/↓

转到定义处​

ctrl + 鼠标左键 或者 f12

光标移动到上一个历史位置或者下一个​

alt + →/←

注释代码块​

shift + alt + a

个人自定义习惯​

扩大缩小选择范围​

ctrl w/q

注释代码块​

ctrl + shift + /
