合并 class 的工具函数最佳实践（参考自shadcn-ui项目）

cn 函数可以作为工具函数放在utils中，用于合并多个 CSS 类名。它结合了 clsx 和 tailwind-merge 两个库的功能。

clsx 用于处理条件类名, 支持条件判断, 支持数组, 支持对象, 支持字符串。

tailwind-merge 用于合并tailwind类名, 避免重复类名, 避免样式冲突, 支持数组, 支持对象。

import { clsx, type ClassValue } from "clsx" // 用于处理条件类名, 支持条件判断, 支持数组, 支持对象, 支持字符串
import { twMerge } from "tailwind-merge" // 用于合并tailwind类名, 避免重复类名, 避免样式冲突, 支持数组, 支持对象

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}

(选择 clsx 而不是 classnames 的原因：1.目前用 clsx 用户要多一点点。2.当前其他兄弟项目也在用)

css及tailwind文件目录结构

src/
├── components/         # 可复用组件
│   ├── layout/         # 布局组件
│   ├── ui/             # 基础 UI 组件
│   └── widgets/        # 业务组件
├── pages/              # 页面
├── styles/             # 全局样式
│   ├── globals.css     # 全局 CSS
│   └── utilities.css   # 自定义工具类
├── utils/              # 工具函数
│   └── classNames.ts   # clsx 辅助函数
└── config/             # 配置文件
    └── tailwind.config.js

工具类的应用：

  1. 直接作为工具类使用

在 HTML 或 JSX 中，可以使用text-{color}、bg-{color}、border-{color}等形式：

<!-- 文本颜色 -->
<p class="text-primary">这是主色调文本</p>

<!-- 背景颜色 -->
<div class="bg-primary">这是主色调背景</div>

<!-- 边框颜色 -->
<div class="border-2 border-primary">这是主色调边框</div>

<!-- 按钮示例 -->
<button class="bg-primary text-white hover:bg-primary/90">
  主色调按钮
</button>
  1. 与状态组合使用

结合:hover、:focus等伪类：

<!-- 悬停效果 -->
<button class="bg-primary text-white hover:bg-primary/80 transition-colors">
  悬停变浅的按钮
</button>

<!--1. hover:bg-primary/80
hover:：这是一个状态修饰符，表示该样式只在元素被鼠标悬停时生效。
bg-primary：使用你在 Tailwind 配置中定义的主色调（#165DFF）作为背景色。
/80：设置颜色的透明度为 80%（即rgba(22, 93, 255, 0.8)）。-->

<!-- 焦点状态 -->
<input type="text" class="focus:border-primary focus:ring-2 focus:ring-primary/20">
  1. 响应式

使用断点前缀（如md:）：

断点是 "大于等于"

<!-- 小屏幕显示默认背景，中等屏幕以上显示主色调背景 -->
<div class="bg-gray-100 md:bg-primary">
  响应式背景
</div>

md: 是一个响应式前缀，用于在特定屏幕尺寸及以上应用样式。它属于 Tailwind 的断点系统，而非原生 CSS 语法。

对应的屏幕宽度

前缀屏幕宽度范围等效 CSS 媒体查询
sm:640px 及以上@media (min-width: 640px)
md:768px 及以上@media (min-width: 768px)
lg:1024px 及以上@media (min-width: 1024px)
xl:1280px 及以上@media (min-width: 1280px)
2xl:1536px 及以上@media (min-width: 1536px)

可以自定义响应式屏幕尺寸的断点

// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      screens: {
        'tablet': '768px',  // 等同于默认的 md
        'laptop': '1024px', // 等同于默认的 lg
        'desktop': '1280px', // 等同于默认的 xl
        'custom': '900px',  // 新增的自定义断点
      },
    },
  }
}

配置自定义断电后，可以使用自定义的断点前缀：

<div class="bg-gray-100 custom:bg-primary">
  自定义断点的响应式背景
</div>
  1. clsx 中动态使用

结合clsx处理条件样式

import clsx from 'clsx';

const MyComponent = ({ isActive }) => {
  return (
    <button className={clsx(
      'px-4 py-2 rounded-lg',
      isActive ? 'bg-primary text-white' : 'bg-light-1 text-dark-2'
    )}>
      {isActive ? '激活状态' : '未激活'}
    </button>
  );
};
  1. 透明度调整

使用{color}/{opacity}语法：

<!-- 50%透明度的主色调背景 -->
<div className="bg-primary/50">半透明背景</div>

<!-- 30%透明度的主色调文本 -->
<p className="text-primary/30">淡色文本</p>
  1. 渐变中使用 在背景渐变中引用主色调：
<div className="bg-gradient-to-r from-primary to-secondary">
  从主色到辅助色的渐变
</div>
// AlertComponent.jsx
import React from "react";
import clsx from "clsx";

function Alert({ type, message }) {
  // 组件级样式配置
  const typeClassMap = {
    success: "bg-green-100 text-green-800",
    warning: "bg-yellow-100 text-yellow-800",
    error: "bg-red-100 text-red-800",
  };

  const baseClasses = "p-4 rounded-lg border-l-4";
  const typeClasses = typeClassMap[type] || "";

  return <div className={clsx(baseClasses, typeClasses)}>{message}</div>;
}
